# ⛸ Судейство фигурного катания по системе ISU

Веб-приложение для судейской бригады: ввод элементов программы, GOE,
компонентов и сбавок по (упрощённой) системе судейства ISU, автоматический
расчёт TES / TCS / TSS и формирование печатного протокола / отчёта о
выступлении. Интерфейс полностью на русском языке.

Приложение не требует сборки и бэкенда — это статичные HTML/CSS/JS-файлы,
все данные хранятся локально в браузере (`localStorage`).

## Запуск

Проще всего запустить локальный веб-сервер в корне проекта, например:

```bash
python3 -m http.server 8000
```

и открыть в браузере `http://localhost:8000/`.

(Файл `index.html` в большинстве браузеров можно открыть и напрямую
двойным щелчком, но локальный сервер работает надёжнее.)

## Возможности

- **Соревнование** — название, место, дата, дисциплина (мужское/женское
  одиночное катание, парное катание, танцы на льду), сегмент программы,
  состав судейской бригады (2–9 судей), технический персонал.
- **Участники** — список фигуристов/пар с номером старта, именем и
  страной/клубом.
- **Протокол** — для каждого участника: добавление элементов (прыжки и
  каскады, вращения, дорожки шагов, хореографические и танцевальные
  элементы), выставление GOE каждым судьёй (от −5 до +5), флаги недокрута
  (`<`), даунгрейда (`<<`), неясного ребра (`e`), прыжковой секвенции и
  «не засчитан»; оценка 5 компонентов программы каждым судьёй; учёт
  сбавок (падения, нарушение времени, прерывания и т.д.). Итоги TES/TCS/
  TSS считаются автоматически.
- **Результаты** — итоговая турнирная таблица по сумме баллов (TSS) с
  сортировкой по местам.
- **Печать/отчёт** — по каждому участнику и по соревнованию в целом можно
  сформировать печатный протокол (кнопка «Печать / PDF» — печать в PDF
  через диалог браузера).
- **Настройки** — таблицы базовых стоимостей элементов, процент GOE на
  шаг и коэффициенты компонентов программы редактируются в формате JSON.
- **Экспорт / импорт** — все данные соревнования можно сохранить в файл
  JSON и загрузить обратно (в т.ч. на другом компьютере/у другого судьи).

## Важное замечание о таблицах баллов

Базовые стоимости элементов и коэффициенты компонентов, зашитые в
приложение по умолчанию (вкладка «Настройки»), являются **примерными
справочными значениями** и могут не совпадать с официальной актуальной
таблицей ISU (Scale of Values) на текущий сезон. Для реального судейства
отредактируйте таблицы на вкладке «Настройки», вставив туда официальные
значения ISU. Модель начисления GOE также упрощена: используется единый
процент от базовой стоимости за каждый шаг GOE (по умолчанию 10%,
настраивается), а не полная официальная таблица очков GOE для каждого
элемента.

## Структура проекта

```
index.html          — разметка приложения
css/style.css        — стили интерфейса и печатной формы
js/data.js            — справочные таблицы ISU (базовые значения, компоненты)
js/storage.js         — состояние приложения и localStorage
js/scoring.js         — расчёт TES/TCS/TSS
js/report.js          — формирование печатных протоколов
js/ui.js              — рендеринг интерфейса и обработчики событий
js/main.js            — точка входа
```
