## Лаборатория клеточных автоматов

`index.html` — интерактивное HTML5-приложение с пятью разными клеточными
автоматами в одном интерфейсе (переключаются выпадающим списком):

- **Игра «Жизнь» (обобщённая)** — правило задаётся вручную в нотации `B/S`
  (Born/Survive), есть готовые пресеты: Conway's Life, HighLife, Day & Night,
  Seeds, Life without Death, Replicator, Maze, Diamoeba — плюс библиотека
  паттернов (планёр, пульсар, ружьё Госпера, космический корабль).
- **Wireworld** — 4-состояньевый автомат для моделирования цифровой логики
  (пусто / проводник / голова и хвост электрона) с кистью для рисования схем
  и готовыми примерами (кольцевой генератор, импульс по проводу).
- **Мозг Брайана** — 3-состояньевый автомат (выключена / горит / угасает),
  даёт хаотичные бегущие искры.
- **Муравей Лэнгтона** — агентный автомат: муравей поворачивает и красит
  клетки под собой, из хаоса вырастает регулярная «автострада»; можно
  добавлять несколько муравьёв одновременно.
- **Элементарный автомат Вольфрама (1D)** — одномерный автомат с 256
  возможными правилами (включая классические 30, 90, 110, 184), каждое новое
  поколение рисуется отдельной строкой под предыдущей.

Общие элементы: старт/пауза, покадровый шаг, случайная инициализация,
очистка, регулировка скорости, рисование на поле мышью и горячие клавиши
(`Space`, `S`, `R`, `C`). Откройте файл прямо в браузере.
