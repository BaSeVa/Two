# Конструктор карт городов

Процедурный генератор и редактор карт вымышленных городов. Всё построение
опирается на детерминированный генератор псевдослучайных чисел: одно и то же
зерно (seed) всегда даёт один и тот же город, а ссылка на карту полностью
описывает её содержимое.

Открывается двойным щелчком по `index.html` — сборка и зависимости не нужны.

```bash
# либо через любой статический сервер
npx http-server -p 8080 .   # затем http://localhost:8080
```

## Возможности

**Генерация**

* зерно (seed) — вводится вручную или бросается кубиком;
* эпоха: средневековая (кривые улицы, плотный старый город) и современная
  (правильная сетка, широкие проспекты, промзоны);
* число кольцевых улиц и радиальных проспектов;
* извилистость улиц, плотность застройки, доля зелени;
* река с мостами на пересечениях с дорогами, городская стена с башнями и
  воротами, пригороды с полями и лесами за стеной.

**Конструктор**

* 13 типов кварталов: цитадель, площадь, храмы, старый город, торговля, жилой,
  окраина, промзона, пристани, парк, поля, лес, вода;
* выберите тип в «кисти» и щёлкните по кварталу — он перестраивается на месте,
  остальной город не меняется;
* правая кнопка мыши возвращает кварталу случайный тип, `Ctrl+Z` отменяет,
  «Сбросить правки» убирает все ручные изменения;
* каждая правка попадает в адрес страницы, поэтому ссылкой можно поделиться.

**Оформление и экспорт**

* четыре стиля: «Пергамент», «Чертёж», «Ночь», «День»;
* подписи кварталов (названия не повторяются) и подсветка типов кварталов;
* статистика: население, число строений, площадь в стенах, кварталы;
* экспорт карты в PNG 2000×2000, сохранение и загрузка города в JSON, ссылка.

**Управление**

| Действие | Как |
| --- | --- |
| Масштаб | колесо мыши / щипок |
| Сдвиг | перетаскивание |
| Информация о квартале | щелчок без выбранной кисти |
| Новый город | `R` |
| Вписать в экран | `F` |
| Отменить правку | `Ctrl+Z` |

## Как это устроено

Город описан в полярных координатах. Кольцевые улицы — окружности, радиус
которых модулирован суммой нескольких синусоид (отсюда «живые», неровные
кольца), радиальные проспекты — лучи с небольшим изгибом. Пересекаясь, они
режут город на ячейки-кварталы.

Каждая ячейка — прямоугольник в параметрических координатах `(u, t)`, который
отображается в мир функцией `cell.map(u, t)`. Поэтому вся дальнейшая работа
(деление на кварталы, участки и дома, отступы под улицы) — это рекурсивное
деление обычного прямоугольника, а кривизна улиц получается автоматически при
отображении. Никакого отсечения многоугольников не требуется.

Дальше по слоям:

1. река — сплайн Катмулла — Рома через город, участки у воды освобождаются под
   набережные, а на пересечениях с дорогами ставятся мосты;
2. тип квартала выбирается взвешенной жеребьёвкой в зависимости от кольца
   (центр — старый город и торговля, окраина — слободы и промзона, у воды —
   пристани);
3. квартал делится на застроенные участки, часть участков остаётся пустой —
   это дворы и проезды;
4. парки заполняются деревьями и прудами, поля — бороздами, площади — фонтаном.

Ключевая деталь: у каждой части карты свой поток случайных чисел
(`CM.rngFor(seed, 'cell:3:7:market')`). Благодаря этому изменение одного
квартала не перетасовывает остальной город, а любая карта восстанавливается
из зерна и списка правок.

## Файлы

| Файл | Назначение |
| --- | --- |
| `index.html` | разметка интерфейса |
| `styles.css` | оформление панели и холста |
| `src/rng.js` | детерминированный ГПСЧ (cyrb128 + mulberry32) и потоки чисел |
| `src/geometry.js` | геометрические утилиты |
| `src/names.js` | названия города и кварталов |
| `src/generator.js` | построение плана города |
| `src/render.js` | отрисовка на canvas, четыре стиля |
| `src/app.js` | интерфейс, камера, редактирование, экспорт |
