# Two
Two_Claude

## Клеточный автомат

`index.html` — интерактивная реализация игры «Жизнь» Конвея на HTML5 Canvas.
Откройте файл в браузере: клик по полю оживляет/убивает клетки, есть старт/пауза,
пошаговый режим, случайная инициализация, регулировка скорости и набор готовых
паттернов (планёр, пульсар, ружьё Госпера, космический корабль).
