# F1 Race Simulator

Симулятор гонки Формулы 1 — статичное веб-приложение (HTML/CSS/JS, без сборки и зависимостей).

## Запуск

Просто откройте `index.html` в браузере, либо поднимите локальный сервер:

```bash
python3 -m http.server 8000
```

и перейдите на `http://localhost:8000`.

## Возможности

- 20 пилотов в 10 командах со своими характеристиками (скорость, стабильность, езда по мокрой трассе, надёжность)
- Живая визуализация гонки на SVG-трассе
- Таблица позиций в реальном времени с износом шин и статусами (круг/пит-стоп/сход)
- Случайные события: пит-стопы, поломки (сход), смена погоды (дождь/сухо), обгоны
- Настройки: количество кругов, скорость симуляции (1x–8x), пауза/продолжение, генерация новой стартовой решётки
- Итоговый подиум и таблица результатов по завершении гонки
